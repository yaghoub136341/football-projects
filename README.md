# ⚽ برنامهٔ گرافیکی جدول لیگ برتر ایران (Windows)

یک برنامهٔ دسکتاپ کامل برای مدیریت **جدول لیگ برتر خلیج فارس** که:

- ✅ در ابتدا **هیچ داده‌ای ندارد** — همه‌چیز را خودتان وارد می‌کنید.
- ✍️ **ورود دستی** تیم‌ها، بازیکنان، نتایج/بازی‌های پیش‌رو و اخبار هر تیم.
- 📸 **واردات از اسکرین‌شات**: از جدول یا نتایج اسکرین‌شات بگیرید (Win+Shift+S)،
  برنامه با OCR متن را استخراج و به ردیف‌های جدول/بازی تبدیل می‌کند؛
  اگر OCR نصب نباشد می‌توانید متن تصویر را خودتان تایپ کنید و پارسر همان را می‌فهمد.
- 💾 ذخیره در **SQLite** داخل پوشهٔ `~/LeaguePro/league.db` تا بعداً بشود از آن‌ها در
  **پیش‌بینی** استفاده کرد (مدل پواسون + امتیاز قدرت تیم).
- 🖱 با **دابل‌کلیک روی هر تیم** در جدول، صفحهٔ جزئیات آن باز می‌شود:
  اخبار، ۵ بازی گذشته، ۵ بازی پیش‌رو (با درصد برد/مساوی/باخت)، قدرت تیم، بازیکنان و گلزنان.
- 🔮 تب مستقل **پیش‌بینی** برای هر دو تیم.
- ↔️ رابط کاملاً **راست‌به‌چپ** فارسی با ظاهر تیره (CustomTkinter).

## اجرا روی ویندوز

1. پایتون ۳.۱۰+ را از [python.org](https://www.python.org/downloads/) نصب کنید
   (تیک *Add Python to PATH* را بزنید).
2. کتابخانه‌ها:
   ```bat
   pip install customtkinter pillow
   ```
3. اجرای برنامه:
   - دوبار کلیک روی `start.bat`، یا
   - ```bat
     python run.pyw
     ```

### ساخت فایل اجرایی EXE + نصبی (Windows)
روی `build_exe.bat` دابل‌کلیک کنید. این اسکریپت به‌طور خودکار:
1. کتابخانه‌های لازم (`customtkinter`, `pillow`, `pyinstaller`, `nsis`) را نصب می‌کند،
2. آیکون برنامه را از `make_icon.py` می‌سازد (`assets\LeaguePro.ico`)،
3. فایل اجرایی تک‌نفره می‌سازد: **`dist\LeaguePro.exe`** (با آیکون اختصاصی)،
4. فایل نصبی ویزارددار می‌سازد: **`installer\LeaguePro-Setup.exe`**
   (میان‌بر دسکتاپ + منوی شروع + حذف از Control Panel).

> برای ساخت فایل نصبی، ابزار [NSIS](https://nsis.sourceforge.io/Download) لازم است؛
> پکیج pip آن به‌صورت خودکار نصب می‌شود. اگر در دسترس نبود، فقط EXE ساخته می‌شود
> و پیام راهنما نمایش داده می‌شود.

آیکون برنامه: `assets\LeaguePro.ico` (نمایشگر امتیاز روی زمین چمن ⚽) — هم در نوار وظیفهٔ
ویندوز، هم روی فایل EXE و هم در نصب‌کننده استفاده می‌شود.

### OCR فارسی (برای واردات از اسکرین‌شات)
- Tesseract for Windows را نصب کنید:
  <https://github.com/UB-Mannheim/tesseract/wiki>
  (در هنگام نصب زبان **Persian/fas** را اضافه کنید.)
- سپس `pip install pytesseract` (اختیاری؛ بدون آن هم برنامه مستقیم CLI را صدا می‌زند).
- اگر OCR نصب نبود، در تب «📸 واردات از اسکرین‌شات» متن قابل‌مشاهدهٔ تصویر را
  در کادر وسط تایپ/چسبانی کنید و «تحلیل متن» را بزنید.

## روش استفاده از واردات اسکرین‌شات
1. از سایت جدول لیگ (football365 / varsary / …) اسکرین‌شات بگیرید.
2. تب «📸 واردات از اسکرین‌شات» → «📋 خواندن تصویر کلیپ‌بورد» (یا انتخاب فایل).
3. متن استخراج‌شده را بررسی و در صورت لزوم اصلاح کنید → «🔍 تحلیل متن».
4. «💾 ذخیرهٔ نتایج تحلیل‌شده در برنامه» — تیم‌های جدید خودکار ساخته می‌شوند،
   آمار ردیف‌ها ذخیره و بازی‌های شناسایی‌شده ثبت می‌گردند.

قالب خطوط قابل‌فهم توسط پارسر (فارسی یا انگلیسی، اعداد فارسی/عربی/لاتین):
```
۱ پرسپولیس ۳۰ ۲۱ ۵ ۴ ۶۰ ۲۰ ۴۰ ۶۸        ← نام تیم + بازی/برد/تساوی/باخت/GF/GA/GD/PTS
پرسپولیس 2 - 1 استقلال                    ← نتیجهٔ یک بازی
سپاهان - تراکتور                          ← بازی برنامه‌ریزی‌شده
```

## ساختار پروژه
```
run.pyw            ورودی اجرای برنامه (مناسب double-click در ویندوز)
start.bat          اجرای سریع با نصب خودکار کتابخانه‌ها
build_exe.bat      ساخت EXE + فایل نصبی (با آیکون اختصاصی)
make_icon.py       ساخت آیکون assets/LeaguePro.ico
installer/LeaguePro.nsi  اسکریپت نصب‌کننده NSIS
lig/app.py         رابط گرافیکی (RTL) + پنجرهٔ جزئیات تیم
lig/data.py        دیتابیس SQLite، جدول، آمار، قدرت تیم، مدل پیش‌بینی
lig/ocr_import.py  OCR و پارسر اسکرین‌شات
lig/screenshots/   آرشیو اسکرین‌شات‌های وارد شده
```

## محاسبهٔ «قدرت تیم»
قدرت = ۵۵٪ میانگین امتیاز بازیکنان (وزن‌دار بر اساس پست) + ۴۵٪ عملکرد جدولی
(امتیاز کسب‌شده به ازای هر بازی). با هر بار ورود اطلاعات تازه محاسبه و ذخیره می‌شود
و مبنای پیش‌بینی‌های اولیه (قبل از پر شدن آمار گلزنی) است.

## پشتیبان‌گیری
دیتابیس یک فایل است: `C:\Users\<کاربر شما>\LeaguePro\league.db`
با کپی کردن آن می‌توانید اطلاعات را به سیستم دیگری منتقل کنید.
